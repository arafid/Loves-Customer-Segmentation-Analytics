# Data

The raw case-competition CSV files are intentionally excluded from this repository because they were provided for an academic case competition and may be subject to sharing restrictions.

To reproduce the analysis, place the original files in this folder using either the canonical name or the original uploaded name:

- `DRIVER_LOOKUP.csv` or `DRIVER_LOOKUP-Afnan_Rafid.csv`
- `DRIVER_3_YEAR_AGGS.csv` or `DRIVER_3_YEAR_AGGS-Afnan_Rafid.csv`
- `DRIVER_MONTHLY_CAMPAIGNS.csv` or `DRIVER_MONTHLY_CAMPAIGNS (1).csv`
- `DRIVER_MONTHLY_PRODUCT_SALES.csv`
- `STORE_LOOKUP.csv`

The notebook and `src/analysis.py` support these filenames.
